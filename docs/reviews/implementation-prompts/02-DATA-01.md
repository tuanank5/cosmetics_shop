# DATA-01 · Review store, seed, tests

Khi owner giao prompt này, hãy thực hiện duy nhất DATA-01, Phase 1, và dừng sau checkpoint G2. BeautyShop là monolith Java 21, Spring MVC, Thymeleaf, JPA/JDBC, MariaDB và MongoDB cho nội dung review. Controller nhận HTTP/form, service giữ nghiệp vụ/transaction, repository đọc và ghi dữ liệu.

## Mục tiêu và quyết định

Một Mongo bean sau interface, bỏ SQL store/runner/config và SQL seed nội dung, tách trạng thái tải. Index guard lúc recovery để bảo đảm unique Giữ SQL kiểm người mua/tên và backup bảng cũ, không chuyển dữ liệu; mock fixture chỉ cho test.

Giữ các quyết định owner mới nhất. Bảng review MariaDB cũ chỉ lưu lịch sử; không xóa, đồng bộ, ghi kép hoặc chuyển sang Mongo. Giữ quy tắc giá/ảnh SKU hiện tại. Phạm vi thanh toán Admin là trạng thái hiệu lực như chi tiết. Nhãn màn quản lý cả Customer và Admin là “Quản lý tài khoản” (UI-01C phụ trách); giữ các vai trò hiện tại.

## Kiểm thử, nghiệm thu và quay lui

- Thiết lập fixture mô tả ở các bước trên. Tạo/cập nhật test cho nhánh thành công, lỗi và biên vừa đổi; giữ test nghiệp vụ cũ còn hiệu lực. Regression gate: **G2 SauMua_MongoDanhGia_Test, MongoTat_MariaDb_Test, ThongKeServiceTest, GoiYPhoBienServiceTest, 2 create cùng item**.
- Dùng JDK 21, chạy `mvn -o test` và `mvn -o -DskipTests package` khi đổi code. Theo profile liên quan chạy tích hợp MariaDB/Mongo bằng database trống riêng, ghi môi trường và số chạy/skip/lỗi. Không chạy seed hoặc restore lên DB owner. Thiếu môi trường phải ghi rõ gate nào còn hở. Với UI kiểm keyboard, no-JS và responsive. Owner tự nhập tài khoản nếu cần.
- Chỉ nghiệm thu khi: **Không còn runtime/seed nội dung SQL, restart Mongo-off và recover an toàn, core mua sắm hoạt động; unavailable rõ cả KPI**. Báo kết quả quan sát riêng với nhận định từ mã.
- Rủi ro và phương án quay lui: Không mở write nếu index sai/quyền thiếu; đóng review hoặc dùng binary tương thích ép Mongo/runner off, tuyệt đối không bật store SQL. Đây là phương án trình owner khi cần; bảo toàn dữ liệu, không dùng lệnh phá hủy hoặc tự đảo thay đổi của gói khác.

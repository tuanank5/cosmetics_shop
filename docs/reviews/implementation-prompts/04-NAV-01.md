# NAV-01 · Home/nguồn/back

## Cập nhật sau AUTH-02

Kiểm saved request của login thật, quay về /account/security sau link và ngữ cảnh danh sách Admin. Loại token, state, callback và URL ngoài site khỏi nguồn Back. Kiểm login từ checkout, LINK/REAUTH và Back từ Admin chi tiết về q/page. [Nghiệm thu AUTH-02](../AUTH-02-nghiem-thu-xac-thuc.md)

Khi owner giao prompt này, hãy thực hiện duy nhất NAV-01, Phase 3, và dừng sau checkpoint G4. BeautyShop là monolith Java 21, Spring MVC, Thymeleaf, JPA/JDBC, MariaDB và MongoDB cho nội dung review. Controller nhận HTTP/form, service giữ nghiệp vụ/transaction, repository đọc và ghi dữ liệu.

## Mục tiêu và quyết định

Route nguồn allowlist, stable anchor, bổ sung history theo entry; nút logo reset, nút Back restore Giữ no-JS, deep links, quyền truy cập, không lưu PII/draft.

Giữ các quyết định owner mới nhất. Bảng review MariaDB cũ chỉ lưu lịch sử; không xóa, đồng bộ, ghi kép hoặc chuyển sang Mongo. Giữ quy tắc giá/ảnh SKU hiện tại. Phạm vi thanh toán Admin là trạng thái hiệu lực như chi tiết. Nhãn màn quản lý cả Customer và Admin là “Quản lý tài khoản” (UI-01C phụ trách); giữ các vai trò hiện tại.

## Kiểm thử, nghiệm thu và quay lui

- Thiết lập fixture mô tả ở các bước trên. Tạo/cập nhật test cho nhánh thành công, lỗi và biên vừa đổi; giữ test nghiệp vụ cũ còn hiệu lực. Regression gate: **G4 P18/P21 browser, LoginRedirectTest, no-JS/Back/Forward/BFCache/tab mới**.
- Dùng JDK 21, chạy `mvn -o test` và `mvn -o -DskipTests package` khi đổi code. Theo profile liên quan chạy tích hợp MariaDB/Mongo bằng database trống riêng, ghi môi trường và số chạy/skip/lỗi. Không chạy seed hoặc restore lên DB owner. Thiếu môi trường phải ghi rõ gate nào còn hở. Với UI kiểm keyboard, no-JS và responsive. Owner tự nhập tài khoản nếu cần.
- Chỉ nghiệm thu khi: **Logo luôn chương 1, home-popular→PDP→Back đúng vùng/thẻ/slide; fallback mất nguồn an toàn**. Báo kết quả quan sát riêng với nhận định từ mã.
- Rủi ro và phương án quay lui: Hai script tranh scroll; tắt enhancement khôi phục, giữ link server rồi đo lại. Đây là phương án trình owner khi cần; bảo toàn dữ liệu, không dùng lệnh phá hủy hoặc tự đảo thay đổi của gói khác.

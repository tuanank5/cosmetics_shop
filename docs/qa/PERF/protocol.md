Chạy Maven test và package trong clone mới của revision trên, dùng JDK 21. Từ root đặt JAVA_HOME và BASE_PLAYWRIGHT (module playwright-core có WebKit), chạy `powershell -ExecutionPolicy Bypass -File docs/qa/PERF/run.ps1 -Checkout target/perf-baseline -OutputDirectory docs/qa/PERF/baseline`. Yêu cầu Windows có MariaDB 12.2, mongod, Python 3, Node, cache BCrypt 6.5.11 theo CART-01. Runner tạo datadir mới từng lượt. Cho lần lặp dùng thư mục output riêng. Regression MariaDB/WebKit dùng runner QUALITY-FINAL từ cùng checkout, Maven cache được truyền qua MavenRepo.

Ứng viên dùng checkout khác cùng parent. Chép bốn file trong `candidate/source.json`, kiểm hash, chạy `mvn test` và `mvn -DskipTests package` tại checkout rồi truyền thêm `-SourceManifest docs/qa/PERF/candidate/source.json` khi gọi run.ps1 từ root. Các số liệu chẩn đoán bổ sung trong diagnostics.json dùng bảy lần ANALYZE cho từng SELECT thực, số dòng và byte của bản xuất TSV. Chúng được lấy sau phép đo HTTP hoặc bằng `-DiagnosticsOnly` với datadir mới. Chi phí ANALYZE không cộng vào latency HTTP.
